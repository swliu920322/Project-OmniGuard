### Job Description

**Summary**
The AI Solution Architect serves as the chief technical authority responsible for designing, governing, and scaling the multi-tenant AI systems, agentic workflow orchestration, retrieval-augmented generation (RAG) pipelines, and cloud platform infrastructure. This role bridges business product vision with technical execution, converting strategic goals into secure, modular, and high-performing architectural blueprints. The AI Solution Architect provides high-level guidance and system contracts to Full-Stack Engineers A & B, enforcing architectural consistency, multi-tenant security, and token cost optimization across all AI business modules.

---

### Core Functional Scope

**1. Multi-Agent Systems & Workflow Orchestration**

* **Architect Agentic Frameworks:** Design and implement autonomous multi-agent orchestration frameworks (LangChain, LlamaIndex, AutoGen, CrewAI, Semantic Kernel) for complex business workflows.
* **State Management & Tool Use:** Establish deterministic state persistence, tool-calling execution flows, fallback routing, and retry loops for long-running AI tasks.
* **Model Routing & Cost Optimization:** Implement dynamic model selection strategies (e.g., routing simple tasks to lightweight models like GPT-4o-mini and complex tasks to frontier models) to optimize token costs and response latency.

**2. RAG & Enterprise Knowledge Architecture**

* **Vector Database Topology:** Design scalable vector storage and search topologies using Pinecone, Qdrant, Milvus, or pgvector.
* **Advanced Retrieval Strategies:** Implement hybrid search pipelines combining semantic dense embeddings, BM25 keyword matching, reranking models, and contextual chunking strategies.
* **Contextual Accuracy & Evaluation:** Establish evaluation frameworks (Ragas, Trulens) to track faithfulness, context recall, and hallucination rates across enterprise document search.

**3. Multi-Tenant Security, RBAC & Governance**

* **Tenant Isolation & Data Privacy:** Architect strict row-level security and context sandboxing to guarantee complete separation of tenant knowledge bases and preventing cross-tenant context leaks.
* **AI Security & Guardrails:** Define prompt injection defenses, input/output sanitization filters, PII redaction mechanisms, and content boundary guardrails.
* **Governance & Audit Trail:** Design comprehensive audit logging for prompt inputs, model outputs, token consumption, and system execution histories.

**4. Systems Architecture, APIs & Technical Leadership**

* **System Blueprints & API Contracts:** Create high-level architecture diagrams, microservice specifications, and API contracts for backend (Full-Stack Engineer A) and frontend (Full-Stack Engineer B) implementation.
* **Cloud & Microservice Infrastructure:** Architect containerized microservices (Docker/Kubernetes), message queues (Kafka/RabbitMQ), and cloud environments (AWS/GCP/Azure) for high-availability AI services.
* **Technical Governance & Mentorship:** Guide engineering squads, conduct architectural reviews, enforce coding standards, and evaluate emerging AI models and tools.
