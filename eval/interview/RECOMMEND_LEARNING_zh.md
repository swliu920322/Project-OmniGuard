# 学习与内化路线：从“看过答案”到“能解释和验证”

目标是理解当前项目并准备面试，不是增加文档或先学完全部AI技术。主要配合[主手册核心八问](INTERVIEW_DEEP_DRILL_zh.md#core-8)使用。每步先自己想，再读材料，再做一个小验证；卡住就回到具体例子。

**内化的标准：换一个输入仍能判断，追问为什么仍能解释，问证据仍能找到。** 不要求背原句，也不把文件读完或测试全绿当作自己已经理解。

## 第一步：讲清问题与阶段成果

**要想：** 最初担心什么？为什么从做饭机器人缩小到AGV？现在的交付回答了哪个问题？

先不看答案，写四句：我想研究什么；怎样缩小范围；已经做成什么；它能帮助作什么判断。再对照主手册[核心1](INTERVIEW_DEEP_DRILL_zh.md#core-q1)和讲述稿中的[动机与贡献](INTERVIEW_STORY_zh.md)。

示例思路：持续运动时等待云端判断可能来不及，停下来等又有时间代价。当前把部分请求耗时、状态分类和代码动作约束分别做成可检查的内容。这些不是同一项成果：分类满分不能回答车辆能容忍多久。

**交付与掌握标准：** 留下自己的四句话，能分别指出“动机”“实现”“观测结果”；不能把合理担忧说成已测出的损失。第一次先说对这三类，不急着包装成技术亮点。

## 第二步：手算一辆车的一次决定

**要想：** 输入是什么？模型答什么？代码最后允许什么？

先读[中文入门例子](START_HERE_zh.md)第1—6节，再看主手册[核心4](INTERVIEW_DEEP_DRILL_zh.md#core-q4)。在纸上画三栏：输入、模型预测、最终决定。

1. 输入距离20cm、速度1m/s、健康100、电量15%、温度65℃，没有备注。
2. 自己写出完整风险、主要状态和动作要求；先不要运行代码。
3. 假设模型错答正常，预测代码会怎样，模型评分又会怎样。
4. 把数值全部恢复正常，只加“前面可能有人”。如果模型也把备注判为无关，会怎样？

**交付与掌握标准：** 能解释“主要状态只有一个，但风险可以多个”“动作纠正不等于模型答对”；能说明第四种情况可能漏停。这是两个不同错误路径，不是背一句“代码兜底”。不懂字段就返回中文例子，不先背英文。

## 第三步：把解释落实到函数和一个可运行实验

**要想：** 哪个函数接请求，哪个真调用模型，哪个检查，哪个合成动作？

沿[代码地图](BACKEND_CODE_GUIDE_zh.md)第2—7节画一条流程，先看扩展租户分支，暂不通读所有旧路径。再做该页[免费实操](BACKEND_CODE_GUIDE_zh.md#offline-lab)：先预测输出，再运行，最后解释差异。

重点分清：HTTP急停、非法输入可以在外部调用前拒绝；扩展Router中的物理门控却在模型返回后经 `execute()` 应用。只调用 `gate()` 得到SKIP，不能证明整个端点零模型调用。

选读并运行一个对应测试：

```sh
# 从仓库根目录运行；.venv按复现指南准备，命令不调用真实模型
.venv/bin/python -m pytest tests/test_router_v2.py tests/test_extended_endpoint.py -q
```

环境准备见[复现指南](../REPRODUCE.md)。若使用项目已有的 `src/cloud-orchestrator/.venv`，把上面Python路径换成该环境；不要求另外安装一份。

**交付与掌握标准：** 一张自己画的流程图；能从某个测试指出输入、假回复和断言。再改一个教学输入预测结果，而不是只有“所有测试通过”。假模型能证明处理逻辑，不能证明真实模型理解能力或真车停车。

## 第四步：亲自核对数字，而不是背成绩

**要想：** 分母是谁？答对什么？文件哪个字段能算出来？

读主手册[核心5](INTERVIEW_DEEP_DRILL_zh.md#core-q5)、[核心6](INTERVIEW_DEEP_DRILL_zh.md#core-q6)和[数字来源](INTERVIEW_DEEP_DRILL_zh.md#evidence)。运行其中只读公开结果的核对命令，不重跑模型。

| 练习 | 必须解释的问题 |
|---|---|
| 手算281/300与23/72 | 前者是主类，后者是备注状态；为什么不是同一指标？ |
| 拆开300、34、72、55 | 配额、家族、带备注子集、压力集合各是什么？为什么不能都加成独立样本？ |
| 拆开55例压力 | 32次真实请求、13例输入检查、10例注入故障，分别检验什么？ |
| 手算第二轮173/180与77/180，并算差值 | 哪个是备注状态指标？为何53.33个百分点是同题方案差值，不是优化前后？ |
| 找到第二轮原始回复与一条错分 | 用[evidence入口](../experiments/note_vs_rules_v2/evidence/README.md)定位输入、冻结标签、模型回复、规则预测及最终动作；复算已有记录不请求模型 |
| 找一项耗时的样本数、中位数和P95 | 测的是哪一段？同一条件还是不同跑次？不能用分类成绩替代时间证据 |
| 看300/300的区间与家族说明 | 为什么记录级区间不能消除合成数据及家族相关性的局限？ |

**交付与掌握标准：** 选一个成绩和一个耗时，现场打开来源字段、写出计算和口径。别人换问另一指标时，能说如何查，不记得数字也不猜。公开汇总没有的字段不能假装已经逐条核实。

## 第五步：解释设计选择，并接受反例

**要想：** 为什么这样做？不用它行不行？增加了什么成本？什么证据会改变选择？

对应主手册[核心2](INTERVIEW_DEEP_DRILL_zh.md#core-q2)、[核心3](INTERVIEW_DEEP_DRILL_zh.md#core-q3)、[核心7](INTERVIEW_DEEP_DRILL_zh.md#core-q7)。每次只选一个问题：

- 数值风险可直接算，为什么还引入模型？现有证据支持备注理解上的对照，不证明更完善规则一定不行。
- 为什么三个角色串行？能解释职责，但没有单次与三段的受控比较，就不能说三段更快或更优。
- 超时后返回停车，是否就安全？还要看等待期间的运动、请求耗时和物理执行，当前不能从后端返回值推出真车安全。

每次写“当前方案—替代方案—代价—已有证据—缺少的验证”。这是练习设计判断，不要求现在实施替代方案或花钱实验。

**交付与掌握标准：** 能给出一个反例，主动修正结论中的条件。比如“慢是网络导致”应改成“目前没有拆分网络、排队与生成时间，无法判断原因”。不知道原因不等于没有成果，仍可讲清测到了哪段及它对选型的意义。

## 第六步：变成自己的表达和贡献故事

读主手册[核心8](INTERVIEW_DEEP_DRILL_zh.md#core-q8)和[回答方法](INTERVIEW_DEEP_DRILL_zh.md#answer-method)。不要直接朗读稿件。

1. 关掉材料，用30秒讲问题、做法和一项成果，再用两分钟补一个关键选择和例子。
2. 随机选核心八问中的三题。每题先答主问题，再应对一个分支；不必一次主动讲完所有分支。
3. 对照主手册逐分支核查漏答，区分“不知道事实”“没讲清理由”“没有证据”“只是术语陌生”。每次修一个问题。
4. 下次练习先不看稿，再答同题并换一个输入；能复述原句却不会换例子，说明还没掌握。
5. 选一个自己真实参与的决定：当时现象、本人行动、AI协助、验证结果。没有回忆或记录的部分待核实，不把刚学会的解释写成过去独立设计。

**交付与掌握标准：** 录音或自己的文字回答，附一个具体纠正。表达采用“直接回答→理由或行动→关键证据→对选择的意义”，范围在需要的位置说明，不把每题都讲成局限清单。真人口述验收和陌生人复现仍按实际完成情况记录，练习不自动改变验收状态。

## 每次练习怎样安排

有15—25分钟时：先脱稿答一题，查一个函数或字段，运行或手算一次，再用自己的话重答。时间只是安排建议，不是学会的保证。一次不同时练技术概念、全部数字和职业规划。

只在自己的笔记或主手册对应题下留这五行，不再建新稿：

```text
今天的问题：
我原先怎么想／怎么答：
核对了哪个函数、字段或测试：
我改正了什么，为什么：
下次不看稿要回答的一个变体：
```

给AI的陪练要求：

```text
先让我回答，每次只追问一个问题，不先给标准答案。
分开指出：漏答的分支、推理缺的条件、未核实的事实、陌生术语。
用项目里的一个具体例子解释，再让我换个例子重答。
涉及数字请给文件与字段，没读取就说无法核实。
纠正写回原题，不新建一份平行讲稿，不虚构本人经历。
```

## 学习到哪里就够，什么暂时不学

能脱稿讲清问题、顺着函数说明一次决定、查出数字来源、解释一次失败与取舍、说明本人真实行动，就开始模拟面试，不等所有专题学完。发现新问题再回到对应一步。

Agent概念、业务harness与职业路线按具体追问补读，见[目录](README.md)。RAG、真机视觉、Azure重新部署、正式新实验都不是理解本轮项目的前提。日后若求职方向明确需要，再单独安排；本轮整理不触发模型调用或部署。
