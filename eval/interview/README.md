# 简历、项目理解与面试练习

**日常核心材料：**

1. [项目设计决策与调用栈实操](PROJECT_DESIGN_THINKING_zh.md)：**第一推荐阅读**。从车间常识到 8 级函数调用栈，提供单点 3 行最小可运行代码与完整单脚本组装实战，吃透 80% 核心设计思想。
2. [面试主手册](INTERVIEW_DEEP_DRILL_zh.md)：先看核心8问的66个分支答案与依据，按每题回答顺序理解，再压缩口述；15问细节与数字来源按需查阅。
3. [学习与口述练习](RECOMMEND_LEARNING_zh.md)：怎样读代码、核对数字、训练思考与表达，每天10～20分钟即可起步。

旧review仅保留跳转入口，历史讨论在Git中，不再作为当前修复清单。以后直接更新这两份对应位置，不继续增加平行讲稿。

口述时先看主手册的[回答结构](INTERVIEW_DEEP_DRILL_zh.md#answer-method)：先回答、用理由与证据支撑，再讲结果意义；范围说准确，但不把“还没做”当每题统一收尾。

## 每次练习只留下一个变化

先自己答，再核对，再改一个错误。能讲清“为什么做、代码怎么走、数字怎样算、边界在哪里、本人做了什么”，比继续扩展稿件更有价值。

本人口述、真实分工与人类陌生人复现等事项，按实际证据更新；不把AI预演写成真人复现，也不把刚学会的解释写成过去已独立作出的决定。
