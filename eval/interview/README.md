# 面试学习入口：先理解，再用自己的话讲

这里服务于两个目标：看懂自己做过的项目，能在面试中解释具体选择和证据。不是把所有材料背下来，也不要求先扩建项目。

## 只沿一条学习路线走

先打开 **[学习与内化路线](RECOMMEND_LEARNING_zh.md)**，从第一步开始。每次完成一个小练习，再决定是否进入下一步。

| 顺序 | 要回答的问题 | 实际产出 |
|---|---|---|
| 1 | 我为什么做，实际做成了什么？ | 用自己的话写四句项目介绍 |
| 2 | 一条输入怎样变成判断和动作？ | 手算一个多风险例子，再改变一个条件 |
| 3 | 代码在哪里调用模型、在哪里限制动作？ | 画请求流程，运行一次免费假模型实验 |
| 4 | 数字说明什么，来源在哪里？ | 亲自核对一项分数、一项耗时和各自口径 |
| 5 | 为什么这样设计，换个条件会怎样？ | 对一个方案说出理由、代价和未验证的替代方案 |
| 6 | 我能脱稿讲清并接住追问吗？ | 30秒介绍、两分钟展开、随机三问及一次纠正 |

答题时使用 **[面试主手册](INTERVIEW_DEEP_DRILL_zh.md#core-8)** 的核心八问。八问及其分支保留完整；15问拓展和数字来源是查询资料，不是额外的背诵任务。先自己答，再查对应分支，不必从头读到尾。
