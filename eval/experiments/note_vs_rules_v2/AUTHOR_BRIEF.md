# 给独立测试作者的说明（本轮：备注理解，规则与模型对照）

你只需要：规范、覆盖计划、配额、数据格式、公开开发材料的排除名单。**你不会收到、也不应该去找**：R3 的内部规则（`r3.py`、词表）、任何模型预测或模型错误分析、旧的私有测试和旧私有包。不能保证你完全不知道任务规则，请如实告知你实际看过什么。

## 0. 先交什么（2026-11-15 更新）

**第一次只交“家族与表达类型覆盖计划”，不要先写满 180 条句子。** 覆盖计划包括：至少 60 个家族的名称与一句话说明；每个家族对应的表达现象（直接说法、多分句、转折、指代与省略、否定范围、历史与当前、条件与指令、不确定表达、对象并列、缩写、合理错别字、与前方无关的人或物）；每个家族落在哪种备注状态、哪种语言、配正常还是有风险的遥测。保管者先核对这份计划与第 3 节的配额（能不能凑出六状态×三语言×两种遥测，每家族不超过 3 条），通过后你才写具体句子。

## 1. 任务一句话

为 AGV 仿真的“可选备注”写 **180 条** 带备注的记录。备注只谈一个话题：**前方有没有人或障碍**。每条记录由 5 个遥测数字和一句备注组成，并给出你认定的备注状态。目的不是考倒某个方法，而是写出自然、可被独立标注的备注。

## 2. 备注状态（规范 1.0，`eval/spec/LABEL_SPEC.md` 第 8 节）

| 状态 | 含义 |
|---|---|
| `AFFIRMED_CURRENT` | 说现在有人或障碍 |
| `UNCERTAIN` | 说可能有、不确定（保守地按需要停车处理） |
| `NEGATED` | 说现在没有（含“通道畅通”） |
| `HISTORICAL` | 说的是之前的事 |
| `HYPOTHETICAL` | 说的是条件或指令（“如果……就……”） |
| `IRRELEVANT` | 与前方的人或障碍无关 |

多分句备注按分句标注后合并：**说现在状态的分句优先于过去、条件和无关**；现在状态之间 `AFFIRMED_CURRENT` > `UNCERTAIN` > `NEGATED`。一个“没有”“之前”之类的词只决定它所在的分句，不决定整句。请先读规范原文再写。

## 3. 配额（保管者会用脚本核对；不满足会被退回）

- 180 条，**六种备注状态各 30 条**；每种状态里 **中文、英文、中英混合各 10 条**；
- 每种状态 **15 条配正常遥测、15 条配已有数值风险**（距离<30、温度>60、血量<50、电量<20、速度>2.5 之一或多个）；正常遥测上的“当前肯定／不确定”共 30 条，是备注独有的停车风险，这个子集会单独报告；
- **至少 60 个语义家族，一个家族最多 3 条**。数值变体、改写、翻译不算新家族。**家族划分和名单要在写具体句子之前先写下来并提交给保管者**；
- 物理门控和急停不混入：血量必须>0 且电量≥5；不要出现 `estop` 字段；
- 备注长度≤500 字符；数值最多 2 位小数，在合同范围内（距离 0–2000、速度 0–5、血量 0–100、电量 0–100、温度 −40–150）。

## 4. 内容覆盖（不是对任何词表的针对）

请自然地覆盖：直接说法；多分句（转折、并列）；指代与省略（“刚才有人，现在走了”）；否定范围；对象不同的并列（“没有人，但有箱子”）；常见缩写；**合理的**错别字（不要为凑错而堆极端写法）；以及与前方无关但提到人或物的句子（排班、仓库内其它位置等）。不得阅读 R3 代码，不得按任何词表漏洞出题。

## 5. 隔离要求

- 家族和句子**不得与公开开发材料重合**：精确重合由 `check-data` 检查；语义重合由保管者另查。排除材料：`eval/dev/dev_set.jsonl`、`eval/dev/families.json`、`eval/dev/stress/stress_dev.jsonl`、`eval/spec/ambiguous_examples.json`。
- 不得把旧已用测试的样本改数值后当新题，也不要凭记忆重写旧题。**旧私有测试已经丢失（`eval/LIMITATIONS.md` 第 22 条），保管者无法再逐条核对，所以这一条只能靠你的自觉并在交付说明里写明你是否见过旧题；结果里会披露“未能与旧私有测试去重”。**
- 初始标签由你**独立**给出；之后由另一个新会话先对抽样做**盲标**（每种状态至少 30%，向上取整，即每种 9 条共 54 条，封存哈希后），再由复核者看初始标签做全量复核。分歧和裁决全部披露；无法裁决的句子在调用前删除，并以同配额补足、写明替换原因。

## 6. 数据格式（JSONL，一行一条）

| 键 | 说明 |
|---|---|
| `id` | 唯一字符串，保持私有 |
| `family_id` | 非空字符串（家族名单承诺中的名字） |
| `telemetry` | 恰好 `distance_cm`、`velocity_ms`、`hp`、`battery_pct`、`temperature_c` |
| `note` | 非空字符串 |
| `note_status` | 上表六选一 |
| `language` | `zh` / `en` / `mixed`；必须与备注的实际文字一致（含汉字且含英文单词=mixed） |
| `gold` | 可选；若给，运行器会重算并核对，**不信任文件里的值** |

不得有其他键（含 `estop`）。交付：文件本身（私有，不进仓库）、家族名单承诺（提前）、标注报告（原始一致率、kappa、分歧与裁决）。开发者只会看到**文件哈希和统计**。
