## 核验与保存边界

在本目录运行 `shasum -a 256 -c SHA256SUMS`，可核对全部41个文件。根清单不包含自身；包内原清单仍保留。17个压缩包逐成员检查，以及4份参考文档文本检查，未检出当前API Key或所检查的常见凭据模式；此检查不是全部未知秘密的绝对保证。没有纳入 `.env` 或本机运行凭据。

历史包保留当时的本机路径、暂存路径、候选标签和过程状态，不为改写叙述而修改原包。它们不表示那些绝对路径在其他机器上仍存在；恢复到自选目录，按本仓库的规范和入口核验。当前冻结成绩不由旧候选或旧手册覆盖。

本目录为普通Git文件，不依赖Git LFS。原 `.local-archives/` 继续作为被忽略的本机副本，但恢复项目时不再依赖它存在。
