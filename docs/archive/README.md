# Historical archive

This directory preserves material that may explain how the project evolved but is not current system documentation.

Contents:

- audits/ — point-in-time reviews and redesign discussions;
- dashboard-live/ — superseded live-dashboard design and execution notes;
- environment-tests/ — point-in-time Azure outputs and resource observations;
- plans/ — completed, abandoned, or uncommitted proposals;
- interviews/ — presentation and interview narratives;
- prompts/ — reusable or historical AI prompts;
- system-design/ — superseded meta-system designs.

Archived documents may contain stale paths, old benchmark values, future-state architecture, personal career analysis, or presentation language. They are intentionally excluded from current-document indexes and validation.

Use Git history when the exact original context matters. Promote an archived idea back into current documentation only after checking it against current code and evidence.
