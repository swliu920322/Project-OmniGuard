## 三、供应链深化方向

### 3.1 两个核心概念

| 概念 | 含义 | 投资含义 |
|---|---|---|
| **供应链匹配度** | 某标的是否真的在这条链上、处于哪一环、营收占比多少 | 匹配度错了 = 买错票 |
| **供给程度（紧缺度）** | 某环节产能/供需景气：利用率、交货周期、价格、订单能见度 | 紧缺度错了 = 接盘在高位 |

### 3.2 企业会不会公示供应链？（如实说）

**绝大多数公司不会完整公示**。可用的披露分层：

| 来源 | 披露内容 |
|---|---|
| 美股 10-K / 港股年报 | 大客户（>10% 营收）须点名；**供应商通常只给比例，不给名字** |
| A 股年报 | 前五大供应商/客户名称 + 占比 |
| ESG / 供应链责任报告 | 苹果每年公开 200+ 供应商名单；台积电、鸿海等有供应链报告 |
| 财报电话会 / 业绩会 | 管理层讲产能、资本开支、订单能见度 |
| 行业研究机构 | TrendForce / SemiAnalysis / Counterpoint / Omdia（付费）→ 利用率、HBM 供给、晶圆启动量 |
| 拆机 / 供应链名录 | TechInsights、iFixit；公司官网供应商责任页 |

> 结论：整体供应链程度 = **行业研究 + 财报披露 + 一线声音（博主/新闻）** 三方拼，单一来源不完整。

### 3.3 查询整体供给程度的数据源

- **免费**：财报电话会/新闻中的数字信号（资本开支、利用率%、订单量、涨价函）；海关/产业协会数据（中国海关、台湾工业局）；多方博主的同向印证
- **付费**：TrendForce 月报（DRAM/NAND/HBM 价格与供给）、SemiAnalysis 订阅
- **自建**：关键词紧缺度指数（见 P1）

## 四、待办清单

### P0 — 高价值、低成本（本地可做，几乎零额外 AI 成本）
- [ ] **紧缺度环比趋势**：跨窗口（7/30/90d）对比同品类紧缺度变化（↑/→/↓），在报告层落地
- [ ] **受益/受损 → 股价逻辑**：把紧缺度传导到"定价权提升方 / 成本承压方"，前端可视化

### P1 — 中期
- [ ] **关键词紧缺度指数（零 AI 时间序列）**：对归档推文按"紧缺/涨价/扩产/过剩"关键词打分，逐窗口生成 0-10 指数，形成趋势曲线
- [ ] **价值链多跳知识图谱**：upstream→midstream→downstream 延伸为可点击的多层依赖图
- [ ] **匹配度核实底稿**：对高信心标的，用拆机报告/供应链名录/财报占比打底，标注"确认真实供应商/待核实"

### P2 — 需要外部资源
- [ ] 接入付费行业数据（TrendForce / SemiAnalysis）校准紧缺度
- [ ] 财报电话会 / 业绩会文本的结构化抽取（capex、利用率、订单）
